Nền tảng API & Tài liệu Developer

Xây dựng nhanh hơn với tài liệu & API chuẩn hóa.

Fizzle cung cấp hệ thống quản lý API, tài liệu tích hợp và xác thực đa lớp — mọi thứ bạn cần để triển khai sản phẩm.

fizzle.config.ts 
import { defineConfig } from 'fizzle';

export default defineConfig({
  project: 'my-api',
  auth: {
    strategy: 'jwt',
    mfa: true,
  },
  docs: {
    openapi: './openapi.yaml',
    theme: 'mintlify',
  },
});
  • Quản lý API key & phân quyền chi tiết
  • Tài liệu OpenAPI tự động từ mã nguồn
  • Xác thực JWT & OTP an toàn đa lớp
